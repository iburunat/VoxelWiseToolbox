demo_studyforrest
=================

— Group analysis of an open naturalistic dataset

Description
-----------

Extends the acoustic-power analysis to multiple StudyForrest participants, demonstrating group maps, cluster-extent correction, and intersubject correlation.

Prerequisites: each subject's run normalised to MNI152 and resampled to the toolbox grid (see demo/studyforrest/README.md and sf_to_mni152.sh), plus the annotation files.

Treat the group statistics as illustrative. With fifteen subjects, the group analysis mainly shows whether the single-subject pattern replicates across participants and demonstrates the toolbox functions on real data.

% ---- configuration ------------------------------------------------------- Set this to your own StudyForrest download before running.

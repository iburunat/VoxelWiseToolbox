demo_xcorr
==========

DEMO_XCORR  Voxelwise lagged cross-correlation with fMRI data
-------------------------------------------------------------

Demonstrates fmri_xcorr by computing the cross-correlation between a double-gamma HRF regressor and simulated fMRI data across a range of temporal lags. The peak lag map reveals which voxels show haemodynamic delays relative to the regressor.

**Functions demonstrated:**

fmri_xcorr, fmri_doublegamma, fmri_regionmask, fmri_effdf, fmri_p2r, fmri_showslices

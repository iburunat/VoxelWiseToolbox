fmri_makecmap
=============

Builds a colormap from anchor colours and their positions.

Description
-----------

Creates a colormap from two or more anchor colours. Each anchor sets the exact colour at a specified position in the colormap, and the colours between anchors are generated by linear interpolation. Moving an anchor changes where its colour appears and how much of the colormap is used for the transitions to the neighbouring colours.

Usage
-----

.. code-block:: matlab

   cmap = fmri_makecmap(colors)                       % evenly spaced anchors
   cmap = fmri_makecmap(colors, positions)
   cmap = fmri_makecmap(colors, positions, n)

Inputs
------

- **COLORS** -- K x 3 matrix of anchor colours in [0, 1], ordered from the low end of the colour range to the high end.
- **POSITIONS** -- K-element vector specifying where each anchor colour appears in the colormap. Values must be strictly increasing and are rescaled internally to span the full colormap. The spacing between positions controls the length of each colour transition. For example, with three colours, [1 20 100] places the middle colour near the low end, while [1 50 100] places it at the centre. Default: evenly spaced.
- **N** -- Number of colours in the result. Default 256.

Outputs
-------

- **CMAP** -- N x 3 colormap, ready to pass to any of the display functions.

WHY THIS IS A SEPARATE FUNCTION
-------------------------------

Colormap construction and data display are handled separately. This function creates a non-uniform N x 3 colormap that can be passed to any toolbox viewer, without requiring additional colour-scaling arguments in each display function.

Examples
--------

.. code-block:: matlab

   % Even blue-grey-red, the toolbox default shape
   cmap = fmri_makecmap([0 0 0.8; 0.7 0.7 0.7; 1 0 0]);

   % Same colours, but blue gives way to grey quickly and grey to red slowly.
   % Useful when negative values are few and should stay saturated.
   cmap = fmri_makecmap([0 0 0.8; 0.7 0.7 0.7; 1 0 0], [1 20 100]);

   % Five anchors, evenly spaced
   cmap = fmri_makecmap([0 0 1; 0.5 0.7 1; 1 1 1; 1 0.6 0.5; 1 0 0]);

   % Use with any viewer
   fmri_showslices(t_map, 1, 2, [-8 8], [], [], 1, cmap, 4.14);
